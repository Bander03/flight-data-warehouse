## Format rules from guide #4 (checklist before printing)

- Cover: course name (bold, size 18, Heiti / small 2), the other cover lines bold size 16; lists all members with student IDs, group number, teacher **Prof Yan Zhu**, date.
- Sections 2 to 5: MS Word, size 11, Times New Roman.
- Figure captions **below** figures, table captions **above** tables; figures and tables numbered separately; page numbers on every page.
- Code in the report: at most one third of an A4 page per listing (Times New Roman size 10.5, "5 hao", as the builder sets it); longer code goes to an appendix. The DW creation statements take at most one third of the whole report.
- Every OLAP function: practical meaning (not steps), the MDX/SQL, a result screenshot, a short analysis.
- Teacher's note: the software environment (versions, installation, settings) must be described concisely in at most one A4 page: section 3.2, subsection "Software environment and configuration". Keep code and screenshots of results (repository, `report/figures/`).
- Sections 4 and 5: one part per member, headed by their name, in their own words.

## Rule for writing

Numbers come from `data/processed/profile_before_after.md` and `docs/DATA_FINDINGS.md`; screenshots are listed in `docs/screenshot-checklist.md`. Do not invent results: every finding in section 3(3) must come from a real run of the cube.

## Build the Word report

```
python tools/build_report.py          # writes report/build/FlightDW_Course_Project_Report.docx (not in git)
python tools/build_report.py --check  # lists placeholders, instructions, empty references and uncaptioned tables
```

The converter applies the guide #4 formatting (cover fonts, Times New Roman 11, code in size 10.5, page numbers). Write table captions **above** the table and figure captions **below** the figure, as Markdown, with the token `N` instead of a number: a bold line `**Table N** ...` directly before every pipe table (except the cover's student table), `![Figure N ...](../../docs/figures/name.png)` for a picture (path relative to the section file) and `Figure N` in a screenshot placeholder. The builder numbers tables and figures separately in document order (Table 1, 2, ...; Figure 1, 2, ...); in the text write "the table below" instead of a number. Notes for the authors are single lines `*(Instruction: ...)*`: they are not printed (`--keep-instructions` prints them). `--check` lists the remaining placeholders, instructions, empty reference entries and tables without a caption, and exits 1 while any is left. Open the result in Word once, check the page breaks, and export the PDF from Word.
