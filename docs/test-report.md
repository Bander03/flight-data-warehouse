## Limitations (accepted and documented)

1. **Prepared data, not real traffic.** Routes, stopovers, dates, aircraft and 240 airline tickets are generated by documented rules; findings describe the prepared data. Supplemented tickets are flagged (`IsSupplemented`).
2. **Stopover versus direct is not like-for-like:** stopovers exist only on routes of at least 900 km, so the price difference mixes distance and stopover effect. Stopover ground time is not in the data.
3. **Distinct counts do not add up** over groups; the data show it only for the one passenger with two segments.
4. **Environment:** the cube needs SQL Server Developer with Analysis Services in Multidimensional mode; the warehouse tests and the SSIS package drop and rebuild `FlightDW`, so the read grant for the cube must be re-run afterwards (`sql/05_grant_ssas_read.sql`).
5. **SSIS in Visual Studio:** the package runs with `dtexec`; Visual Studio could not open a hand-written project, so figure D4 is drawn from the package file (stated in the report).
6. **Screenshots** show the Windows user and computer name in the SSMS status bar.
7. **Raw data and the teacher's guides are not in git** (size, ownership); the raw folder must be copied to the repository root before step 2.
